# Wednesday 18 November 2026 — The World in One Day

An entry for the make.fun `news-image-20261118` bounty. `main.ts` (Node 22,
standard library only) draws a 1024x1024 editorial poster entirely in code —
a hand-written 5x7 bitmap font, simple vector pictograms, and a small PNG
encoder — and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png` (default
`/output`). No network, no assets; two runs produce byte-identical output.

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
